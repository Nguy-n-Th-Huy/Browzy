## Why

Live comparison on dauthau.asia found correct results from both extensions, but Browzy showed non-clickable bare URLs, restarted lists, verbose reports and misleading action counts. The user authorized all five improvements including meaningful progress, real step evidence and difficult browser scenarios.

## What Changes

- Render safe bare links, multiline ordered lists and readable tables.
- Put requested results first and collapse secondary details without hiding incomplete outcomes.
- Show real work phases and separate executed operations from planning/read/check activity.
- Associate real before/after evidence and available historical screenshots with steps, preserving capture/privacy controls.
- Cover obstruction, delayed results, empty results, pagination and changed filters in scenario tests and live QA.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `browser-assistant-panel`: Readable reports and truthful phase/count/evidence presentation.
- `jev-decision-layer`: Bounded phase/evidence events and browser scenario guarantees.

## Impact

Touches sidepanel Markdown/rendering/model/labels, Jev runtime/text-helper, existing screenshot/artifact transport and focused tests. Additive events retain historical compatibility. Completion verification, grounded URLs, permissions, masking and screenshot settings remain authoritative.

## Non-goals

No provider replacement, agent rewrite, login automation or new external screenshot upload. A single benchmark does not establish general speed superiority.
