Skills

Reusable local instructions and resources the side panel assistant can run — imported once, used from then on with no terminal.

What a skill is

A skill is a folder on your own machine containing a SKILL.md file (a name, a description, and instructions) plus, optionally, other resource files it refers to by relative path. Importing a skill copies that folder into the extension's own app-owned storage — it never runs anything in it, and it never touches your original folder afterward.

No fixed catalog

Skills are not bundled with this extension and there is no built-in library to browse. You bring your own skill folders (written by you, or obtained separately) and import them explicitly, one at a time, through Settings. A reference screenshot showing a skill named skill-creator in an earlier design document does not mean that skill ships with this extension, and does not imply this extension can execute arbitrary host code — see "What a skill cannot do" below.

First-time setup (one-time, needs your file system)

  1. Open the side panel, click the settings (gear) icon, then Skills.
  2. Type or paste the full path to your skill's folder into Đường dẫn thư mục skill (the folder must contain a SKILL.md file at its top level) and click Nhập thư mục.
  3. Only that exact folder is read. Nothing else on your computer — no other project, no other app's configuration, no home-directory scan — is ever touched by an import.
  4. Review the imported entry's name, description, and source path, then turn its toggle on to enable it. A skill stays disabled (and unusable) until you explicitly enable it.
This step happens once

Once imported and enabled, a skill remains available every time you open the browser afterward — you do not need to re-import it, and you do not need a terminal, a CLI, or a Claude Code session to use it day to day. Everything from here on happens inside the browser side panel.

If an import is rejected

What you'll seeWhat it means
"Metadata skill không hợp lệ"The folder has no valid SKILL.md, or it is missing a name/description.
"Trùng tên skill"Another imported skill already uses that same name. Remove the old one first, or use Nạp lại (refresh) on it instead.
"Đường dẫn không an toàn" / "Liên kết thoát ra ngoài thư mục"A file or a symlink inside the folder points outside the folder itself. Rejected before anything is copied.
"Yêu cầu quyền chưa được hỗ trợ"The skill needs to run a script or write files — see "What a skill cannot do" below. Import still succeeds (so you can see what it is), but it cannot be enabled.

Daily use — browser only, no terminal

Once a skill is imported and enabled, using it is entirely inside the side panel:

  • Type its name. Ask the assistant to do the task in your own words, mentioning what you need — an enabled skill whose description matches can be picked up automatically, with the transcript identifying which skill ran.
  • Or invoke it directly. Type / in the message box to open a picker of every enabled, explicitly-invocable skill, with its name and description. Keep typing to filter by name or description; use the arrow keys and Enter to choose one, or Escape to close the picker without choosing.

Selecting a skill from the picker inserts the exact command into the message box — for example:

/tom-tat-trang

It does not send anything by itself. Add whatever task details you want, then press Send when you're ready — you always see exactly what will be run before it runs.

A skill disabled in Settings (or never imported) cannot be run this way even if you type its name by hand — it will not appear in the picker, and typing it manually is rejected with an explanation instead of being silently ignored or run anyway.

Managing imported skills

  • Enable / disable — the toggle on each entry. Disabling takes effect immediately: the skill can no longer be run, whether typed by hand or invoked automatically, from that point on.
  • Nạp lại (refresh) — re-reads the skill from its original source folder. Editing the source folder's files on disk has no effect on a skill already imported until you explicitly refresh it; a conversation already using the earlier version keeps using it even if you refresh mid-conversation, and only a new conversation picks up the refreshed content.
  • Gỡ bỏ (remove) — deletes only the app's own copy. Your original folder on disk is never touched or deleted — you can re-import from it again later.

What a skill cannot do

Importing and enabling a skill never grants it — or the assistant while running it — any authority beyond what the assistant already has. Specifically, a skill can never:

  • Change your provider Base URL, API key, or model settings.
  • Read your saved credentials or any other secret.
  • Expand which browser tab or window the assistant can act on.
  • Grant itself shell access, arbitrary file writes, or any tool beyond reading its own imported files and using the browser tools you already approved.
Script- or write-requiring skills

A skill whose files need to run a shell script, or need to write to disk, is detected at import time and clearly marked. It can be imported (so you can see what it is), but it can never be enabled — you'll see an explicit "unsupported capability" message rather than the skill silently gaining shell access, and rather than the assistant claiming it ran something it didn't. Initial support covers instruction-and-resource skills and skills that drive the existing browser tools.
